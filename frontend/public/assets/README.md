# Dossier Assets

Ce dossier contient les ressources statiques de l'application, y compris le logo de l'application.

## Utilisation
Vous pouvez y stocker vos images (par exemple `logo.png`, `logo.svg`, etc.).
Dans votre code React, ces images seront accessibles directement via le chemin relatif :
`"/assets/nom_de_votre_logo.png"`
